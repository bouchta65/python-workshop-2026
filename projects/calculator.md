Exercise 1 — Basic Python Calculator

Create a simple calculator in Python.

Requirements
Display a menu:
===== CALCULATOR =====

1. Addition
2. Subtraction
3. Multiplication
4. Division
5. Exit
Ask the user to choose an option.
If the user chooses 1–4, ask:
How many numbers do you want to calculate?
Ask the user to enter all the numbers.
Perform the selected operation and display the result.
After the result, show the menu again.
If the user chooses 5, stop the program.
